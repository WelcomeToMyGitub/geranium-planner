# 天竺葵育种规划器

一个给《元梦之星》「繁花奇育·天竺葵」活动用的育种规划工具。
输入库存和配方，自动算出：**还缺什么、该种多少、按什么顺序合成**。

## 功能

- **库存三栏**：花材 / 生长中 / 种子，分开记
- **配方表可编辑**：亲本、产物、产物概率、成功率都能改，随时补新配方
- **撤销 / 重做**：配方编辑支持 Ctrl+Z / Ctrl+Y
- **配方独立保存**：和库存分开存，另有导出 / 导入 JSON
- **全局种植计划**：按地块数算总种子、轮数、本轮铺法
- **现在就能合**：只列你手上真有花材的配方，标「推荐 / 值得试 / 已够」
- **敏感性分析**：成功率整体 ±30%，看轮数范围

## 模型

核心是把游戏规则折成「折合多少基础种子」：

```
一次合成成功 = 1 朵成品 + seedYield 颗种子
种子种下再收   = harvestYield 朵 / 颗

所以一次成功实际顶： 1 + seedYield × harvestYield 朵

还需要的成功次数 = ceil(剩余缺口 ÷ 上面这个数)
期望尝试次数     = 成功次数 ÷ 成功率 ÷ 产物概率
```

每种花取「期望成本最低」的那条配方，再从成品往基础种反推物料需求（BOM）。

## 目录

```
geranium-planner/
├─ index.html          页面骨架
├─ css/style.css       样式
├─ js/data.js          默认花 / 配方 / 库存
├─ js/model.js         纯计算（不碰 DOM）
├─ js/ui.js            渲染与事件
├─ js/main.js          入口
├─ data/               预留：以后把配方挪成 JSON
├─ tools/serve.py      本地预览
└─ docs/               文档
```

## 运行

直接双击 `index.html` 即可（脚本都是普通 script，不依赖服务器）。

或者：

```bash
python tools/serve.py
# 打开 http://localhost:8000
```
